# Brand assets

- `ALTR Brand Identity 1.jpg` — brand kit reference (charcoal #232321, cream
  #eaebdd, mint #c8f2e6).
- `src/` — official logo exports as supplied (wordmark + "A" mark, black and
  cream variants).
- `altr-wordmark.png` (cream) / `altr-wordmark-dark.png` (charcoal) —
  transparent wordmarks built from the official exports; the cream one is
  used on report covers and the roster band.
- `altr-mark.png` (mint, per the brand kit) / `altr-mark-dark.png`
  (charcoal) — the "A" glyph; mint version is used in reports.

To override the wordmark used in reports (e.g. with a vector master), drop in
`altr-logo.svg` or `altr-logo.png` — it takes precedence automatically.
