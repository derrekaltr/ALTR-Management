# ALTR Domain Research

Availability sweep of "Altr" domains for the three-company ecosystem (ALTR Management,
ALTR Services "Signal", ALTR Media Group), run **2026-11-01**.

**Method:** every result verified against authoritative registry data — Verisign RDAP
for `.com`/`.net`, rdap.org → registry RDAP for other TLDs, whois spot-checks for TLDs
with unreliable RDAP (`.co`, `.io`, `.gg`). Availability changes daily; re-verify before
buying anything from the "available" lists if significant time has passed.
