# ALTR Management — Company HQ

Single organized home for all ALTR Management work. Every project that used to live in its own
Conductor workspace now lives in a section folder here. Sister companies (ALTR Services, ALTR
Media Group) are indexed in [ECOSYSTEM.md](ECOSYSTEM.md) and will get their own hubs later.

## How to work in this repo

- **Tasks**: each section has a `TASKS.md` board with `Now / Next / Done`. Add new tasks there;
  agents working in this repo should read and update the relevant board.
- **Projects**: each migrated project keeps its own subfolder (with its original README/HANDOFF)
  under its section, so context never gets lost.
- **Migration status**: [MIGRATION.md](MIGRATION.md) tracks where every old Conductor project went.
